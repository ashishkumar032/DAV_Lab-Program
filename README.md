Introduction to Python for Data Analytics:
This repository contains three beginner-friendly Jupyter Notebook experiments covering data analysis with Python.

Experiments:

1. NumPy and Pandas Basics
Covers:
- Creating and modifying NumPy arrays
- Array arithmetic and filtering
- Creating a Pandas DataFrame
- Selecting columns, rows, and slices

  
2. Exploratory Data Analysis
Creates a sample dataset and explores it by:
- Viewing rows, dataset dimensions, and column types
- Computing descriptive statistics
- Counting missing values
- Finding and removing duplicate rows


3. Data Visualization
Creates a sample dataset and visualizes it with:
- Histograms
- Box plots
- Scatter plots
- Pair plots
- Correlation heatmaps

  
Running the Notebooks
1. Clone or download this repository.
2. Open the notebooks in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the cells from top to bottom.
